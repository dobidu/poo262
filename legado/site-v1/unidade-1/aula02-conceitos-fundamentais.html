Aula 02 · 30/abr

Conceitos Fundamentais: Objetos, Classes e Mensagens

🎯 Objetivos
  • Distinguir classe (molde) de objeto (instância)
  • Compreender mensagens e o mecanismo de despacho
  • Identificar atributos de instância vs. de classe
  • Usar a terminologia OO corretamente em português e inglês
§1

Classe vs. Objeto

Uma classe é um molde — define estrutura e comportamento. Um objeto é uma instância concreta em memória, com seus próprios valores de atributos.

cpp Classe como molde, objetos como instâncias
▶ playground
// Classe: define o molde — existe em tempo de compilação
class sample {
    float amplitude_;      // atributo de instância — cada objeto tem o seu
    float sample_rate_;
public:
    explicit sample(float a, float sr = 44100.0f);
    float amplitude() const noexcept { return amplitude_; }
};

// Objetos: instâncias em memória — existem em tempo de execução
sample s1{0.5f};          // objeto 1: amplitude_ = 0.5
sample s2{-0.3f, 48000};  // objeto 2: amplitude_ = -0.3, rate_ = 48000

// s1 e s2 compartilham o CÓDIGO (a classe), mas têm DADOS independentes
std::cout << s1.amplitude(); // 0.5  — dados de s1
std::cout << s2.amplitude(); // -0.3 — dados de s2
§2

Mensagens e Despacho

Em OO, objetos se comunicam por mensagens. Em C++, uma mensagem é implementada como uma chamada de método. O objeto receptor decide como responder — isso é o fundamento do polimorfismo.

cpp Mensagens em C++ 
// Sintaxe de mensagem: receptor.mensagem(argumentos)
s1.set_amplitude(0.8f);    // mensagem "set_amplitude" para s1
float a = s1.amplitude();  // mensagem "amplitude" para s1

// O receptor DECIDE como processar — encapsulamento em ação
// set_amplitude pode validar, logar, notificar observers, etc.
// O remetente não sabe (nem precisa saber) o que acontece internamente
💡
Mensagem ≠ Chamada de função

Uma chamada de função em C é estática — o compilador sabe qual função chamar. Uma mensagem OO pode ser resolvida em tempo de execução (polimorfismo dinâmico), dependendo do tipo real do receptor.

⚠️
O que o LLM costuma errar

LLMs confundem atributos de instância com atributos de classe (static). Peça explicitamente que demonstre os dois e mostre que objetos independentes têm dados independentes.
