ℹ️
JavaScript moderno é OO

JavaScript com ES6+ tem herança via prototype chain e polimorfismo. É considerado OO — mas com um modelo diferente do C++. Python também é OO completo.

§3

Single vs. Multiple Dispatch

Em C++, a resolução de método virtual depende apenas do tipo do receptor (single dispatch). Em linguagens com multiple dispatch (Julia, Common Lisp), depende dos tipos de todos os argumentos.

cpp Single dispatch em C++ 
class effect {
public:
    virtual void process(audio_buffer& b) = 0; // despacho por tipo de *this
};

// C++ não tem multiple dispatch nativo — workaround: visitor pattern
class effect_visitor {
public:
    virtual void visit(gain_effect& g)   = 0;
    virtual void visit(reverb_effect& r) = 0;
};

⚠️
O que o LLM costuma errar

LLMs frequentemente classificam C++ como 'fortemente tipado' sem mencionar as conversões implícitas problemáticas (int→float→double) e os C-style casts que quebram a segurança de tipos.
