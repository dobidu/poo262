Aula 04 · 07/mai

Transição Python/C → C++ Moderno

🎯 Objetivos
  • Configurar o ambiente: GCC, CMake, GDB, sanitizers
  • Compreender o modelo de compilação C++ (pré-processamento, compilação, link)
  • Usar namespaces, streams e tipos modernos
  • Comparar C++ com C e Python nas construções mais comuns
§1

Configurando o Ambiente

bash Instalação e verificação (Ubuntu/Debian) 
# Compilador e ferramentas
sudo apt install -y build-essential g++-12 cmake git ninja-build

# Verificar
g++ --version   # deve mostrar 12.x
cmake --version # deve mostrar 3.20+

# Primeiro programa
echo '#include 
int main() { std::cout << "Olá, C++17!\n"; }' > hello.cpp
g++ -std=c++17 -Wall -Wextra hello.cpp -o hello && ./hello

# Com CMake
mkdir meu_projeto && cd meu_projeto && cmake -B build
cmake --build build
💡
Sanitizers são seus amigos

-fsanitize=address,undefined detecta memory leaks, buffer overflows e comportamento indefinido em tempo de execução. Use sempre em desenvolvimento.

§3

De C e Python para C++

cpp Equivalências: Python/C → C++17 
// Python: print("hello")       C: printf("hello\n")
std::cout << "hello" << '\n';  // C++ — sem '\n' faltando

// Python: x = [1, 2, 3]        C: int arr[] = {1,2,3};
std::vector v = {1, 2, 3}; // C++ — dinâmico, seguro

// Python: for x in lista:      C: for(int i=0;i int:
int f(int x) { return x * 2; } // C++ — tipos obrigatórios

LLMs neste Tópico

🤖
Prompt sugerido

"Tenho experiência em Python e estou aprendendo C++17. Mostre as 10 principais diferenças que vão me pegar de surpresa, com exemplos de código nos dois lados. Foque em: gerenciamento de memória, tipos, includes, e comportamento de strings."

⚠️
O que o LLM costuma errar

LLMs tendem a listar diferenças óbvias (ponto e vírgula, chaves) e ignorar as perigosas: undefined behavior, object slicing, e a diferença entre cópia e referência em tipos não-primitivos.

04.Compile um programa com -fsanitize=address que acessa memória além dos limites de um vetor. Interprete a mensagem do AddressSanitizer e corrija o bug.
