Sintonia — v1.3 — Operadores em sample e audio_buffer

sample ganha +, *, +=, *= e <<. Mix de buffers via operator+=.

§1

Membro vs. Função Livre

cpp Convenções: quando usar membro vs. livre 
// ✅ MEMBRO: operadores que modificam *this (+=, -=, *=, [])
sample& sample::operator+=(const sample& rhs) noexcept {
    float novo = amplitude_ + rhs.amplitude_;
    amplitude_ = std::clamp(novo, -MAX_AMP, MAX_AMP);  // com clipping
    return *this;
}

// ✅ LIVRE: operadores binários simétricos (+, -, *, ==)
// Livre permite: 2.0f * s E s * 2.0f (comutativo)
sample operator+(sample lhs, const sample& rhs) noexcept {
    return lhs += rhs;   // reutiliza o membro — DRY
}
sample operator*(sample lhs, float factor) noexcept {
    return lhs *= factor;
}
sample operator*(float factor, sample rhs) noexcept {  // comutativo
    return rhs *= factor;
}

// ✅ LIVRE: operator<< para streams (não pode ser membro de ostream)
std::ostream& operator<<(std::ostream& os, const sample& s) {
    return os << "sample(" << s.amplitude() << " @ "
              << static_cast(s.sample_rate()) << " Hz)";
}
§2

Operadores para audio_buffer

cpp Mix e ganho via operadores 
// Mistura dois buffers sample a sample
audio_buffer& audio_buffer::operator+=(const audio_buffer& rhs) {
    if (data_.size() != rhs.data_.size())
        throw std::invalid_argument("tamanhos incompatíveis");
    for (std::size_t i = 0; i < data_.size(); ++i)
        data_[i] += rhs.data_[i];
    return *this;
}

// Aplicar ganho escalar
audio_buffer& audio_buffer::operator*=(float factor) noexcept {
    for (auto& s : data_) s *= factor;
    return *this;
}

// Acessar sample por índice — com e sem const
float& audio_buffer::operator[](std::size_t i) {
    if (i >= data_.size()) throw std::out_of_range("indice fora do intervalo");
    return data_[i];
}
const float& audio_buffer::operator[](std::size_t i) const {
    if (i >= data_.size()) throw std::out_of_range("indice fora do intervalo");
    return data_[i];
}

// Função livre: mix de dois buffers
audio_buffer mix(audio_buffer lhs, const audio_buffer& rhs) {
    return lhs += rhs;  // reutiliza operator+=
}

LLMs neste Tópico

🤖
Prompt sugerido

"Implemente sobrecargas de operadores para uma classe spectrum (espectro de frequências). Inclua: +, -, *, +=, -=, *=, ==, !=, [], <<. Siga as convenções: membro para operadores de modificação, livre para simétricos."

⚠️
O que o LLM costuma errar

LLMs frequentemente: (1) implementam todos os operadores como membros, quebrando a comutatividade, (2) esquecem a versão const de operator[], (3) não retornam *this de operator+=.

Ex.

Exercícios Propostos

01.Implemente operator== e operator!= para sample. Por que comparar floats com == é problemático? Implemente uma comparação com tolerância usando std::abs.
02.Adicione operator[] a audio_buffer (const e não-const). Verifique nos testes que a versão const pode ser chamada em objetos const audio_buffer.
03.Implemente uma função normalize() que retorna um novo buffer com peak_level() == 1.0f, usando os operadores existentes de audio_buffer. Escreva o teste Catch2 correspondente.
04.Por que não se deve sobrecarregar operator&&, operator|| e operator,? Pesquise e explique o problema com o short-circuit evaluation.
