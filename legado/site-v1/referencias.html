LLMs — Recursos e Postura Crítica

A disciplina integra o uso de assistentes de IA como ferramenta profissional legítima — com postura crítica. Alguns recursos relevantes:

RecursoRelevância
Anthropic Claude — claude.aiAssistente com bom suporte a C++ moderno e análise de código
GitHub CopilotAutocomplete integrado ao VS Code — útil para boilerplate
ChatGPT — openai.comBom para explicações conceituais; verificar o código gerado
Prompts do repositóriosintonia/llms/ — prompts validados para modelagem OO
⚠️
Responsabilidade e limites

Você é responsável por todo código que entrega, independentemente de ter sido gerado por IA. LLMs podem: inventar APIs inexistentes, ignorar boas práticas de C++ moderno, esquecer virtual em destrutores, usar new/delete quando smart pointers seriam corretos, e violar SOLID silenciosamente. Sempre compile, teste com sanitizers e revise criticamente.

📖
Leituras sobre IA no desenvolvimento de software

"Thinking Fast and Slow" (Kahneman, 2011) — vieses cognitivos que se aplicam à avaliação de código gerado por IA.
"The Pragmatic Programmer" (Thomas & Hunt, 2019) — mentalidade de artesão que deve guiar o uso de ferramentas de IA.
