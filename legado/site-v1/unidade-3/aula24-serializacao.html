nlohmann/json — Serialização Idiomática

cpp Serializando project com nlohmann/json 
#include 
using json = nlohmann::json;

// Para/de JSON: sobrecarregar to_json/from_json (extensão não-intrusiva)
void to_json(json& j, const audio_buffer& buf) {
    j = json{{
        {{"size", buf.size()}},
        {{"sample_rate", buf.sample_rate()}},
        {{"samples", std::vector(buf.begin(), buf.end())}}
    }};
}

void from_json(const json& j, audio_buffer& buf) {
    auto samples = j.at("samples").get>();
    float sr = j.at("sample_rate").get();
    buf = audio_buffer{samples.size(), sr};
    for (std::size_t i = 0; i < samples.size(); ++i)
        buf[i] = samples[i];
}

// Uso na json_repository:
json j;
j["version"]  = 1;
j["name"]     = project.name();
j["tracks"]   = json::array();
for (const auto& t : project.tracks())
    j["tracks"].push_back(json(t));  // chama to_json
std::ofstream{path} << j.dump(2);   // indentado com 2 espaços

Versionamento de Formato

cpp Compatibilidade entre versões de formato 
// json_repository.cpp — tratamento de versões
std::unique_ptr json_repository::load(const std::string& path) {
    std::ifstream f{path};
    if (!f) throw std::runtime_error{"arquivo não encontrado: " + path};

    json j;
    try { f >> j; }
    catch (const json::exception& e) {
        throw std::runtime_error{"JSON inválido: " + std::string{e.what()}};
    }

    int version = j.value("version", 1);  // default 1 para retrocompat.
    switch (version) {
        case 1: return load_v1(j);
        case 2: return load_v2(j);
        default:
            throw std::runtime_error{
                "versão de formato não suportada: " + std::to_string(version)};
    }
}
💡
Sempre inclua versão no formato

Versione o formato desde o primeiro commit. Adicionar version depois é trabalhoso e quebra arquivos existentes.

⚠️
O que o LLM costuma errar

Serializar hierarquias polimórficas é difícil: o LLM frequentemente esquece de salvar o tipo concreto, impossibilitando a desserialização. Sempre inclua um campo 'type' no JSON.
