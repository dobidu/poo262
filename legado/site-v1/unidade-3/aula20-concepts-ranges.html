Concepts C++20 e Introdução a Ranges

🎯 Objetivos
  • Usar concept para restringir parâmetros de template com sintaxe legível
  • Contrastar concepts com static_assert de C++17
  • Usar ranges básicos: views::filter, views::transform
  • Conhecer o que está no horizonte além de C++17
§1

Concepts — Restrições Legíveis

cpp Concept vs. static_assert — C++20 vs. C++17
▶ playground
// C++17: static_assert (funciona mas mensagem de erro ruim)
template 
class buffer {
    static_assert(std::is_arithmetic_v, "T deve ser aritmético");
};

// C++20: concept (mensagem de erro clara + sintaxe elegante)
template 
concept audio_sample = std::is_arithmetic_v;

// Sintaxe de concept em templates:
template    // versão concisa
class buffer_v2 { ... };

// Ou com requires:
template 
requires audio_sample
class buffer_v3 { ... };

// Concept composto:
template 
concept processable_buffer = requires(T b, std::size_t i) {
    { b[i] }       -> std::convertible_to;
    { b.size() }   -> std::same_as;
    { b.apply([](float s){ return s; }) };
};
§2

Ranges e Views

cpp Ranges básicos — algoritmos sem índices
▶ playground
#include 
#include 
#include 

std::vector samples = get_samples();

// C++17: algoritmos STL tradicionais
std::vector loud;
std::copy_if(samples.begin(), samples.end(),
             std::back_inserter(loud),
             [](float s){ return std::abs(s) > 0.5f; });

// C++20: ranges — composíveis, lazy
auto loud_range = samples
    | std::views::filter([](float s){ return std::abs(s) > 0.5f; })
    | std::views::transform([](float s){ return s * 2.0f; });

// Lazy: nenhum dado é processado até iterar
for (float s : loud_range) { /* processa */ }

Prompt sugerido

"Converta a função buffer::apply(Func f) de C++17 (sem concepts) para C++20, adicionando um concept que restringe Func a ser invocável com T e retornar T. Mostre a mensagem de erro com e sem concept."

⚠️
O que o LLM costuma errar

LLMs às vezes confundem concepts com SFINAE e com static_assert. São mecanismos diferentes: SFINAE é para sobrecarga, concepts são para restrições legíveis, static_assert para verificação em compilação.
