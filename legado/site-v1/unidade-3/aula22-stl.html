Aula 22 · 21/jul

STL: Contêineres, Algoritmos e Iteradores

🎯 Objetivos
  • Escolher o contêiner correto para cada situação
  • Usar algoritmos STL em vez de loops manuais
  • Compreender o modelo iterador e como a STL é extensível
  • Aplicar algoritmos ao processamento de áudio
§1

Guia de Escolha de Contêiner

ContêinerAcessoInserçãoUso típico no Sintonia
vector<T>O(1)O(1) final, O(n) meioAmostras de áudio, lista de efeitos
deque<T>O(1)O(1) ambas as pontasFila de eventos MIDI
list<T>O(n)O(1) em qualquer lugarRaramente — preferir vector
map<K,V>O(log n)O(log n)Config: nome→valor
unordered_map<K,V>O(1) médioO(1) médioLookup frequente por chave
set<T>O(log n)O(log n)Conjunto de plugins únicos
array<T,N>O(1)ImpossívelBuffer de tamanho fixo em stack
💡
Regra default: use vector

Na maioria dos casos, std::vector é o contêiner certo. Sua memória contígua é cache-friendly. Só mude para outro quando tiver razão concreta.

§2

Algoritmos STL no Processamento de Áudio

cpp Algoritmos comuns em contexto de áudio 
#include 
#include 

std::vector buf = get_samples();

// std::transform: aplicar ganho
std::transform(buf.begin(), buf.end(), buf.begin(),
               [](float s) { return s * 0.5f; });

// std::max_element: pico
auto pk = std::max_element(buf.begin(), buf.end(),
    [](float a, float b) { return std::abs(a) < std::abs(b); });

// std::accumulate: RMS
float rms = std::sqrt(
    std::accumulate(buf.begin(), buf.end(), 0.0f,
        [](float acc, float s) { return acc + s*s; }) / buf.size()
);

// std::copy_if: extrair samples acima de threshold
std::vector loud;
std::copy_if(buf.begin(), buf.end(), std::back_inserter(loud),
             [](float s) { return std::abs(s) > 0.5f; });

// std::fill: silenciar
std::fill(buf.begin(), buf.end(), 0.0f);

// std::sort: ordenar por magnitude
std::sort(buf.begin(), buf.end(),
          [](float a, float b) { return std::abs(a) > std::abs(b); });

LLMs neste Tópico

🤖
Prompt sugerido

"Implemente um detector de silêncio em áudio usando apenas algoritmos STL (sem loops manuais): dado um vector<float>, retorne os intervalos [início, fim] onde abs(sample) < threshold por mais de min_duration_samples amostras consecutivas."

⚠️
O que o LLM costuma errar

LLMs tendem a implementar em loops manuais quando a versão STL seria mais clara. Peça explicitamente 'sem loops for/while manuais' e observe se eles conseguem.
